## Task 1: Creating a Spotify Playlist (bullet points)

**Prompt:**

```
I'm new to Spotify and want to create my first playlist. Give me a step-by-step
guide for doing this on the mobile app. Write the answer in bullet points only,
one action per bullet, in the order I should do them. Keep the language simple
and mention the exact buttons or menu names I need to tap.
```

## Task 2: Zomato vs Swiggy (table format)

**Prompt:**

```
Compare the features of Zomato and Swiggy for a regular user in India.
Present the answer as a table with at least three columns: Feature, Zomato,
Swiggy. Cover points like delivery speed, restaurant variety, subscription
plan, offers and discounts, grocery delivery, and app ease of use. Don't write
anything outside the table except one line at the end saying which app suits
which kind of user.
```

## Task 3: Last Five IPL Winners (JSON)

**Prompt:**

```
List the last five IPL winners with the year and the team name. Return the
output only in valid JSON, with no extra text before or after it. Use this
structure:

[
  { "year": 0000, "team": "Team Name" }
]

The list should be ordered from the most recent year to the oldest.
```
