# SESSION 1

*Five structured prompts with the required output formats*

## Task 1: Create a Spotify Playlist

Act as a helpful technology guide. Explain how a beginner can create a
new playlist on Spotify.

**Requirements:** - Give the instructions in the correct order, one step
at a time. - Use bullet points for every step. - Include instructions
for both the Spotify mobile app and desktop/web player. - Explain how to
name the playlist and add songs. - Use simple, clear language and avoid
unnecessary technical terms.

## Task 2: Compare Zomato and Swiggy

Compare the features of Zomato and Swiggy, the food-delivery apps.

**Requirements:** - Present the comparison in a table. - Include at
least these three columns: Feature, Zomato, Swiggy. - Compare at least
six relevant features, such as restaurant discovery, food delivery,
offers, live order tracking, reviews/ratings, and membership benefits. -
Keep each cell concise and easy to understand. - If a feature or benefit
varies by city or changes over time, mention that instead of making an
unsupported claim.

## Task 3: Last Five IPL Winners in JSON

List the five most recent Indian Premier League (IPL) champions,
including the year and winning team name.

**Requirements:** - Return only valid JSON, with no Markdown fences or
explanatory text outside the JSON. - Use a top-level JSON array
containing five objects. - Each object must have the keys `year` and
`team`. - Use the most recent completed IPL seasons and verify the
information before answering. - Ensure the JSON syntax is valid,
including double quotes and commas.

## Task 4: Benefits of UPI Apps

Summarize the main benefits of using UPI apps such as PhonePe and Paytm.

**Requirements:** - Give exactly three short bullet points. - Keep the
entire answer to 30 words or fewer. - Use simple language and focus on
the most important benefits. - Do not add a heading or any extra
explanation.

## Task 5: Book a Movie Ticket on BookMyShow

Explain how to book a movie ticket using BookMyShow for a beginner.

**Requirements:** - Organize the answer using clear headings for each
major step. - Use headings in this style: "Step 1: Search Movie", "Step
2: Select Cinema and Show Time", "Step 3: Select Seats", and continue
until booking is complete. - Explain how to choose a city, movie,
cinema, showtime, seats, and payment method. - Include a final step
explaining how to check the booking confirmation and ticket details. -
Use simple, practical instructions and mention that available options
may vary by location and show.
